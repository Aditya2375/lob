# lob

A limit order book, a matching engine, and a market-making bot quoting into a
simulated market - built from scratch in Java, replayed and re-runnable in the
browser.

**Live demo:** https://aditya2375.github.io/lob/

The demo replays four pinned scenarios generated by the Java engine, and the
"rerun" button executes the same engine ported to JavaScript, verified
bit-identical against the Java original (`tests/parity.mjs`).

## What's inside

- `src/lob/book/` - the order book: price-time priority, FIFO queues per
  level, O(1) cancels via an id map, self-match cancel-back, depth snapshots.
- `src/lob/sim/` - the market: a fair-value random walk, noise takers,
  informed takers that trade toward fair value, and passive background depth.
  Plus the market maker: mid-anchored quotes, volatility-scaled spread,
  inventory skew, hard inventory cap, cancel-replace every two ticks.
- `src/lob/sim/Main.java` - generates the pinned scenario files the site
  replays.
- `web/src/engine.js` - the full engine and simulator ported to JavaScript.
- `web/src/` - the site: canvas charts (price and quotes, depth ladder, PnL
  and drawdown, inventory), trade tape, and mark-out attribution.

## Honest accounting

Every bot fill is attributed by counterparty and marked out against fair
value 50 ticks later. In all four scenarios the bot earns from noise flow and
loses to informed flow - spread capture versus adverse selection, measured
rather than asserted.

This is a simulated market with synthetic agents. No real instruments, no
real money, no data feeds.

## Run it

```sh
make test       # unit tests + JS/Java parity (bit-exact)
make web        # regenerate scenarios and pack docs/
node tests/browser-smoke.mjs   # drives the packed site in headless Chrome
```

Requires JDK 21+ and Node 18+. The site is fully static: `docs/` after
`make web`, or the live link above.

## Scenarios

| scenario | seed | what it shows |
| --- | --- | --- |
| Calm two-sided flow | 11 | steady spread capture |
| Volatile tape | 22 | the spread widens itself |
| Toxic, informed-heavy flow | 33 | adverse selection eats the edge |
| Flash move | 44 | fair value drops 6.00 in one tick |
